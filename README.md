# 🚀 Space Defender - Juego Espacial Adictivo

Un shooter espacial moderno y adictivo desarrollado con HTML5 Canvas y JavaScript puro. ¡Defiende la galaxia de las hordas enemigas!

## ✨ Características Principales

### 🎮 Gameplay
- **Múltiples tipos de enemigos**: Básicos, rápidos, tanques y tiradores
- **Sistema de armas progresivo**: Básica → Doble → Triple → Láser
- **Power-ups variados**: Salud, armas, escudo y velocidad
- **Progresión de niveles**: Dificultad creciente con el tiempo
- **Campo de estrellas animado**: Ambiente espacial inmersivo

### 🎯 Mecánicas Avanzadas
- **Sistema de puntuación**: Puntos basados en tipo de enemigo y nivel
- **Colisiones precisas**: Detección de colisiones optimizada
- **Efectos de partículas**: Explosiones y efectos visuales
- **Sistema de vidas**: 3 vidas con posibilidad de recuperar
- **Persistencia local**: Guardado de mejores puntuaciones

### 🎨 Diseño y UX
- **Interfaz moderna**: Diseño futurista con gradientes y efectos
- **Responsive design**: Adaptable a diferentes tamaños de pantalla
- **Animaciones fluidas**: Transiciones suaves entre pantallas
- **Tipografía especializada**: Fuente Orbitron para ambiente espacial
- **Efectos visuales**: Glows, sombras y gradientes dinámicos

## 🎮 Controles

### Teclado
- **Flechas o WASD**: Mover nave espacial
- **Espacio**: Disparar
- **P**: Pausar/Reanudar
- **ESC**: Menú principal

### Mouse
- **Movimiento**: Control directo de la nave (opcional)

## 🚀 Cómo Jugar

1. **Inicio**: Haz clic en "JUGAR" para comenzar
2. **Movimiento**: Usa las flechas o WASD para mover tu nave
3. **Disparo**: Presiona ESPACIO para disparar a los enemigos
4. **Power-ups**: Recoge los power-ups para mejorar tu nave
5. **Supervivencia**: Evita que los enemigos te alcancen
6. **Progresión**: Avanza de nivel destruyendo enemigos

## 🎯 Tipos de Enemigos

- **🟥 Básico**: Enemigo estándar, fácil de destruir
- **🟨 Rápido**: Se mueve rápido, pocos puntos de vida
- **⬛ Tanque**: Mucha vida, lento, muchos puntos
- **🔴 Tirador**: Dispara proyectiles, peligroso a distancia

## ⚡ Power-ups

- **🟢 Salud (+)**: Recupera una vida
- **🟠 Arma (⚔)**: Mejora tu arma actual
- **🔵 Escudo (🛡)**: Protección temporal contra daño
- **🟣 Velocidad (⚡)**: Aumenta tu velocidad temporalmente

## 🏆 Sistema de Puntuación

- **Puntos base**: Varían según el tipo de enemigo
- **Multiplicador de nivel**: Más puntos en niveles superiores
- **Persistencia**: Las mejores puntuaciones se guardan localmente
- **Ranking**: Top 10 mejores puntuaciones

## 🛠️ Instalación y Ejecución

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Soporte para HTML5 Canvas
- JavaScript habilitado

### Pasos
1. Descarga todos los archivos del proyecto
2. Abre `index.html` en tu navegador
3. ¡Disfruta del juego!

### Estructura de Archivos
```
space-defender/
├── index.html      # Archivo principal del juego
├── style.css       # Estilos y animaciones
├── game.js         # Lógica del juego
└── README.md       # Este archivo
```
